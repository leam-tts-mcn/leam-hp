TikTok Shopで初売上が出ないときの見直し順｜開設後30日で確かめる7か所

更新日：2026年10月15日公開日：2026年10月15日 執筆：株式会社LEAM 編集部

01初売上の前は「売れない」より先に「買えない」を疑う

開設直後で注文が0件のとき、最初に分けたいのは「見られているのに買われない」のか、「そもそも買える状態になっていない」のかです。前者は商品・価格・動画の訴求の問題で、売れない時に見る10のチェックリストで原因を順に潰す領域です。開設から90日の進め方全体は立ち上げ90日ロードマップにまとめています。この記事はその手前、初売上が1件も出ていない段階だけを扱います。

いまの状態先に疑うこと読む記事
開設後、注文が1件もない買える状態と、人が届く経路の切れ目この記事（§02〜§08を順に）
注文は入ったが、伸びない・続かない商品・素材・LIVE・広告など売り方売れない時の10のチェックリスト
週ごとに何をするかを決めたい準備・初回販売・改善・拡大の段取り90日ロードマップ
仕組みそのものを確かめたい3つの売り場とアフィリエイトTikTok Shopとは

この記事が扱う範囲（LEAM作成）

公式のセラー向けコンテンツ自社運用マニュアルも、成長段階の最初を「販売可能な商品がある → 初回注文」と置き、その段階を「トラフィックがまだ蓄積段階にある」と説明しています。最初の1件は、売り方の巧拙より前に、商品が販売できる状態にあり、そこへ人が流れる経路がつながっているかで決まります。当社の運用実感でも、開設後に止まっているショップは、1か所の設定や導線が切れているだけのことが少なくありません。

02最初に、商品が販売できる状態かを確かめる

出品の手続きを終えても、買える状態になっているとは限りません。公式ヘルプ「ショップの設定」は、ビジネスの確認が終わった後の設定として、倉庫の設定、商品の追加、銀行情報の追加、公式TikTokアカウントのリンク設定の4つを挙げています。商品の追加では、商品管理 → 新規商品追加の手順で「ブランド資格」と「カテゴリー資格」の要否を確認するよう案内しています。

カテゴリーによっては、さらに事前の承認が要ります。公式ヘルプ「制限付き商品」は、制限付き商品をTikTok Shopからの事前承認が必要な商品と定義し、認証やテストレポートなどの文書を提出して、カテゴリーの承認プロセスに合格する必要がある場合があるとしています。どのカテゴリーが対象かは禁止商品・制限商品ガイドで整理しています。

当社の運用実感では、開設直後に止まっているショップで最も見落とされやすいのがここです。資格の提出や出品内容の修正を求められたまま、担当者は「出品済み」と認識している状態です。商品ごとの状態の表示名は画面の更新で変わることがあるため、この記事では断定しません。セラーセンターの表示で、出品したすべての商品が販売できる状態にあるかを1件ずつ確かめてください。

⚠️ 4つの設定は、後ろの確認場所につながっている

公式アカウントのリンク設定は§05の商品リンクに、倉庫と出荷テンプレートは§04の配送に直結します。終わらないまま動画を増やすと、後で順番を戻すことになります。開設手続きは開設・出店ガイド、画面の場所はセラーセンターの使い方を参照してください。

03在庫と価格は、SKUごとの在庫と、その場で決められる額かを見る

次に見るのはSKUごとの在庫と価格の見え方です。在庫は商品単位ではなくSKU（色・サイズなどのバリエーション）単位で見ます。当社の運用実感では、選ばれやすいSKUだけ在庫が0のケースや、他の販路との在庫の反映が遅れるケースがあります。公式ヘルプ「アフィリエイトコラボ」も、クリエイターに商品を紹介してもらう際は在庫がどの程度あるか把握しておくことが重要だとし、紹介された商品の在庫がなくなって販売機会を逃さないよう注意を促しています（在庫の持ち方は在庫管理の記事）。

価格は、動画を見た人が比較をせずに決められるかどうかで見ます。公式のコンテンツ自社運用マニュアルは、初回注文を狙う場面の構成ポイントとして、次の設定を挙げています。

項目公式マニュアルに書かれている構成ポイント
クーポン条件を可能な限り緩くし、有効期間を3〜7日に設定する。割引やタイムセールと価格が競合しないようにする
タイムセールタイムセール価格は過去14日間の最低価格以下とし、同じ商品のタイムセールの間隔は72時間以上とする
主要SKU主要SKUに期間限定特典と価格アンカーポイントを設定する

初回注文を狙う場面の構成ポイント（公式のコンテンツ自社運用マニュアルの記載を整理）

割引を作り込む必要はありませんが、クーポンとタイムセールの価格がぶつかっていないかは一度見ておきます。価格そのものの決め方は価格設定戦略、手残りの計算は手数料とカテゴリー別の料率にまとめています。

04送料と配送は、初回注文の前に期限から逆算して整える

配送の設定は、注文が入るまで問題が表に出ませんが、最初の注文が入った瞬間から期限が動きます。公式ヘルプ「ショップの設定」は、設定の中に倉庫と出荷テンプレートの設定を含めています。

送料の条件について、公式のコンテンツ自社運用マニュアルは初回注文を狙う場面で送料無料設定は必須で、最低注文額は設定しないか、低め（2,000円未満）に設定すると書いています。送料の負担は採算に直結するので、§03の価格とあわせて決めてください。

期限は、公式の注文品配送ポリシーに明記されています。営業日は月曜日から金曜日で、土曜日、日曜日、日本の祝祭日は非営業日です。

段階注文品配送ポリシーの記載
集荷待ち注文日の翌営業日から起算して2営業日目の23:59までに、注文ステータスが「集荷待ち」と表示されなければならない
発送済み注文日の翌営業日から起算して3営業日目の23:59までに、注文ステータスが「発送済み」に更新されなければならない
配達完了通常注文は、注文日の翌営業日から起算して5営業日目の23:59までに「配達完了」へ更新する必要がある（予約販売・受注生産・取り寄せ注文は含まない）
自動キャンセル発注日から7営業日を経過しても「集荷待ち」または「発送済み」に変わらない場合、注文は自動的にキャンセルされる
配送方法配送業者が提供する追跡可能配送オプションを使用しなければならない

初回注文から動き出す期限（注文品配送ポリシーの記載を整理）

発送期限の数え方と、遅れたときのペナルティは、発送期限と遅延ペナルティで解説しています。

当社の運用実感では、注文通知の受け手が決まっておらず、初回注文に数日気づかない形でつまずくことがあります。通知の受け手と発送担当を、注文が入る前に決めておいてください。

05ショーケースと商品リンクは、公式アカウントと動画で確かめる

買い手の入口は、公式アカウントのショーケースと、動画に付いた商品リンクの2つです。公式ヘルプの記載は次のとおりです。

項目公式ヘルプの記載
リンクできる数各TikTok Shopアカウントとリンクできるのは、1つの公式アカウントのみ（変更は3回まで）
商品の表示TikTok Shopにアップロードされた商品は、公式アカウントに自動的に表示される
付与される権限リンク設定が終わると、公式アカウントにeコマース動画とLIVEの権限が付与される
動画1本の商品数1つの動画に追加できる商品リンクは最大10件
動画に付けられる商品自分のアカウントのショーケースにある商品のみ

ショーケースと商品リンクのルール（公式ヘルプ「ショップの設定」「動画にショッピングカートを追加する方法」の記載を整理）

ここから読み取れるのは、動画に商品を付けるには、先にその商品がアカウントのショーケースに入っている必要があるということです。公式アカウントには商品が自動で表示されるとされているので、表示されていなければ、§02の商品の状態か、公式アカウントのリンク設定を疑います。動画への追加は、動画の編集が終わったら「リンクを追加」を押し、ショーケースから商品を選ぶ流れです（公式ヘルプ「動画にショッピングカートを追加する方法」）。

付け忘れた動画について、クリエイター向けの公式ヘルプ「既存動画にショッピングカートを追加する方法」は、過去30日以内に投稿され、商品リンクが追加されていない動画に、TikTok Studio → TikTok Shop クリエイターセンター → 「その他機能」＞「商品をリンク」から後で商品を追加できると案内しています。一度追加した商品は変更できません。公式アカウントで同じ画面が使えるかはヘルプに書かれていないので、アプリの表示で確かめてください。

06動画は、商品リンク付きの本数で数える

動画が少なければ、商品が人の目に触れません。公式のコンテンツ自社運用マニュアルは、「販売可能な商品がある → 初回注文」の初期段階について、低頻度のショート動画投稿／試験的な配信で初回注文の達成を加速させるとし、推奨されるサイクルを次のように置いています。

項目初期段階（販売可能な商品がある → 初回注文）の記載
ショート動画Eコマースのアンカーポイント付きショート動画を毎週2〜3本投稿する
LIVE配信0〜1回（15〜30分）。配信予告は任意
主要な指標リーチはコンテンツの表示回数とタップスルー率、LIVEは配信ルームへの入室率、コンバージョンはカート追加率と注文完了率
セラーのツール新規セラーミッションを完了して、トラフィックとプラットフォームのクーポンを獲得する

初回注文までの推奨サイクル（公式のコンテンツ自社運用マニュアルの記載を整理）

数えるのは「アンカーポイント付き」、つまり商品リンクが付いた動画だけです。リンクのない動画は買い物の入口になりません。段階ごとの本数の上げ方は90日ロードマップで扱っています。

初期の主要指標は、どこで止まっているかを読む手がかりになります。表示が少なければ本数、タップがなければ商品リンク（§05）、カートに入らなければ価格・在庫・送料（§03・§04）へ戻ります。動画の作り方は売れるショート動画の作り方、指標の置き方はKPI設計で扱っています。

07クリエイターが0人なら、オープンコラボで見つけてもらう

自社の公式アカウントだけで動画を出し続けるのは、開設直後のチームには負担の大きい作業です。並行して、クリエイターに商品を紹介してもらう経路を開けておきます。公式ヘルプ「アフィリエイトコラボ」は、コラボをオープンコラボとターゲットコラボの2つに分け、初めてのセラーの多くがオープンコラボを利用して、自社製品を選んだクリエイターと、そのコンテンツのパフォーマンスを確認していると書いています。

当社の運用実感では、クリエイターが0人のまま止まっているショップは、少数に招待を送って返事を待ち続けていることが多くあります。まずオープンコラボで見つけてもらえる状態を作り、紹介してくれた人の中から次に招待する相手を選ぶほうが、待ち時間が減ります。招待の作り方はクリエイター招待とコラボの仕組み、アフィリエイト全体の仕組みはアフィリエイトの仕組みで解説しています。

08アフィリエイト設定は、追加済み・報酬率・サンプルを見る

オープンコラボを始めたつもりでも、商品が追加されていなければクリエイターからは見えません。初売上の前に確かめるのは、次の3点です。

確かめる点できている状態
追加済みか主力商品が「Added products（追加済み商品）」にあり、「Not added（未追加）」に残っていない
手数料率推奨コミッション率は参考値で、率はセラーが決めている
無料サンプル申請を受けるかを決め、トグルをそれに合わせている

アフィリエイト設定で見る点（公式ヘルプ「アフィリエイトコラボ」の記載をもとにLEAM作成）

当社の運用実感では、開設後に足した商品が未追加のまま残っていることがあります。手数料率の水準は商材と採算で変わるため、この記事では数字を示しません（決め方はコミッション相場と報酬の決め方）。3点がそろっているのにクリエイターが集まらない場合、原因の切り分けはクリエイターが集まらない原因と対策で扱っています。

09開設後30日は、週ごとに見る場所を決めて見直す

7か所を開設後30日の週ごとに割り振ります。以下は当社の実務上の整理で、公式ヘルプの記載ではありません。前の週の項目が終わっていなければ、先に進まず戻ってください。

時期見直す場所できている状態止まっていたら
1〜7日目① 商品の承認・② 在庫と価格出品した全商品が販売できる状態で、SKUごとに在庫がある資格・承認の提出を最優先にする
1〜7日目③ 送料と配送送料の条件と、通知の受け手・発送担当が決まっている§04の期限の表を、担当者が見る場所に貼る
8〜14日目④ ショーケースと商品リンク公式アカウントに商品が出て、動画すべてに商品リンクがあるリンクのない動画に付け直す
8〜14日目⑤ 動画の本数商品リンク付きの動画を週2〜3本出せている同じ商品の見せ方を変えて本数を確保する
15〜21日目⑥ クリエイター・⑦ アフィリエイト設定主力商品がオープンコラボにあり、サンプルの可否を決めている未追加タブを確認し、主力商品から追加する
22〜30日目全体の見直し表示・タップ・カート・注文のどこで止まるかを言える止まっている段に対応する節（§03〜§06）へ戻る

開設後30日の見直し表（LEAM作成）

💡 ショップパフォーマンススコアが出ないのは、この段階では正常

公式ヘルプ「ショップパフォーマンススコアガイド」によると、スコアは直近60日間に30件以上の注文（不正注文やサンプル注文を除く）の配送が完了すると自動的に付与されます。初売上の前に表示されないのは異常ではありません。出店から180日未満などの条件をすべて満たすショップには、指標スコアが3.5を下回ると3.5まで引き上げる保護措置もあります。

30日たっても初売上が出ない場合は、7か所のどこかに見落としがあるか、商材の見せ方を変える段階です。後者は売れない時に見る10のチェックリストの土台編から進めてください。この手順は初売上を保証するものではなく、買える状態と経路を順に確かめるためのものです。

10まとめ

初売上の前は、売り方より先に買える状態と、人が届く経路を上から順に確かめます。

1. 商品の承認
出品した全商品が販売できる状態か
2. 在庫と価格
SKUごとに在庫があるか。クーポンとタイムセールの価格がぶつかっていないか
3. 送料と配送
送料の条件と、発送期限を守れる担当がいるか
4. ショーケースと商品リンク
公式アカウントに商品が出ているか。動画に商品が付いているか
5. 動画の本数
商品リンク付きの動画が週2〜3本あるか
6. クリエイター
0人ならオープンコラボで見つけてもらう状態を作る
7. アフィリエイト設定
主力商品が未追加タブに残っていないか。報酬率とサンプルの可否を決めたか

11よくある質問

TikTok Shopを開設したのに初売上が出ないとき、最初に何を確かめればよいですか？
出品した商品が販売できる状態かを最初に確かめます。公式ヘルプは、商品管理 → 新規商品追加の手順で「ブランド資格」と「カテゴリー資格」の要否を確認するよう案内しており、制限付き商品は事前承認が必要です。そのうえで、SKUごとの在庫、送料と配送、公式アカウントと動画の商品リンクの順に見ます。
開設直後のTikTok Shopでは、ショート動画を週に何本投稿すればよいですか？
公式のコンテンツ自社運用マニュアルは、「販売可能な商品がある → 初回注文」の初期段階の推奨サイクルとして、Eコマースのアンカーポイント付きショート動画を毎週2〜3本、LIVE配信を0〜1回（15〜30分）としています。数えるのは商品リンクが付いた動画だけです。
TikTok Shopの商品が公式アカウントに表示されないのはなぜですか？
公式ヘルプは、TikTok Shopにアップロードされた商品は公式アカウントに自動的に表示されるとしています。表示されない場合は、商品が販売できる状態かと、公式アカウントのリンク設定が終わっているかを確かめてください。
クリエイターが1人もいない状態で、TikTok Shopのアフィリエイトは何から始めればよいですか？
オープンコラボから始めるのが一つの方法です。公式ヘルプによると、アフィリエイトを初めて始めるセラーの多くはオープンコラボを利用して、自社製品を選んだクリエイターとコンテンツのパフォーマンスを確認しています。主力商品が「Not added（未追加）」のタブに残っていないかも確かめてください。
TikTok Shopで初回注文が入ったら、いつまでに発送すればよいですか？
注文品配送ポリシーでは、注文日の翌営業日から起算して2営業日目の23:59までに「集荷待ち」、3営業日目の23:59までに「発送済み」にする必要があります。発注日から7営業日を経過しても変わらない場合、注文は自動的にキャンセルされます。土日と日本の祝祭日は営業日に数えません。
開設したばかりのTikTok Shopで、ショップパフォーマンススコアが表示されないのは問題ですか？
問題ではありません。公式ヘルプによると、スコアは直近60日間に30件以上の注文（不正注文やサンプル注文を除く）の配送が完了すると自動的に付与されます。初売上の前や注文が少ない段階では表示されません。
